# Art Pipeline

All world art is generated by code in `tools/art/` (Python, Pillow and numpy). There is no hand-drawn or external art yet.

```
python3 tools/art/build.py      # regenerates every asset (~20 s)
```

| File | Produces |
|---|---|
| `common.py` | palette (sampled from the reference images), noise, dithering, outline helpers |
| `world.py` | starter region layout: terrain, collision, props, NPCs, spawn zones -> `src/world/starter.json` |
| `ground.py` | the whole ground layer baked as one image: organic grass/dirt borders with grass lips and tufts, cobbled plaza, river lowered below the banks with earth faces and foam, plank bridge, grass clumps, flowers, pebbles, soft prop shadows |
| `props.py` | trees (3), rocks (3), bushes (2), bridge posts, timber-frame houses (2 roof colours) |
| `chars.py` | hero (front/back x 4 walk frames), Elder, Smith, Hooded Stranger, slime (2 frames), wolf (2 frames) |
| `build.py` | writes `public/assets/art/*.png` and `src/assets/manifest.json` (sizes and ground anchors) |

## Conventions

- **Art pixels:** art is authored at half resolution and drawn at 2x (1 art px = 2 world px). Iso tile = 32x16 art px.
- **Crisp pixels:** camera zoom is chosen so 2 x zoom is a whole number, which keeps every art pixel the same size on screen.
- **Light:** comes from the top-left. Props cast baked shadows toward the bottom-right.
- **Anchors:** each sprite has a ground anchor in the manifest, so the game places its feet or trunk base exactly on the tile.
- **Transparency:** sprites are real RGBA PNGs with transparency (no colour keying).

## Known gaps vs. the reference images

- Less density and variety: no ruins, mushrooms, chests, stumps, or tall flowers yet.
- No elevation (cliffs or stairs), and no caves.
- Characters are small chibi sprites, not the larger detailed hero of the references.
- No dynamic lighting (torches, glow), and the water is not animated yet.
- The UI still uses a plain system font, not a pixel font or panel art.
